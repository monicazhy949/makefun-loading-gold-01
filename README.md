A one-line loading-screen tip (max 200 characters) for tired developers and the AI coding agents beside them: neither of them is actually loading — the human is pretending to review, the agent is pretending to think, and the spinner is the only one actually working.

## Run it

```bash
python3 main.py
```

This prints the entry and writes it to `/output/entry.txt`.
